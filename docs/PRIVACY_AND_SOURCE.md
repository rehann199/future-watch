# Privacy and Source

## What this repository contains

- A written case study of the Future Watch website.
- Screenshots of public pages of the live site.
- A diagram of the architecture.

## What it does not contain

- Production source code (private; no licence granted).
- Environment files, keys, tokens, passwords or service credentials. Sensitive configuration exists in the production project and is excluded.
- Internal identifiers, storage locations, admin screens, analytics data or build-tracking data.
- Personal data of any user or team member.

## Screenshots

All screenshots were captured from the public pages of the live site. No admin or login-protected page appears. The contact-form capture shows empty placeholder fields only.
